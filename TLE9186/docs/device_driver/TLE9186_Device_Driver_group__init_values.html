  • Setting up the MOTIX™ TLE9186QV device driver
  • In detail: MOTIX™ TLE9186QV device driver
  • Modules
    • Shadow Registers

      The Shadow Register holds a copy of the internal registers of the TLE9186.

    • Register Information

      The addresses, masks and bit-positions are necessary to access each an every bit of the TLE9186 device.

    • Initialization Values

      The initialization values are needed for the initialization of the register shadow and are based on the reset value of each register.

    • Types

      The device driver uses AUTOSAR datatypes which need to be defined. This file offers the possibility of either using the platform datatypes or custom data types.

    • Function Layer

      The Function Layer offers API function for either writing to a register or reading from a register.

    • Register Layer

      The Register Layer offers API function for either writing to a register or reading from a register.

    • Service Layer

      The Service Layer is in charge of generating correct MOSI frames based on the information received from the Register Layer. While doing so it calculates the CRC checksum.

    • Application Layer

      The Application Layer is in charge of utilizing the API functions of the device driver to an application code.

    • Hardware Abstraction Layer

      The Hardware Abstraction Layer offers platform depended functionality to the device driver. These functions are used by the Service Layer and the Application Layer.
