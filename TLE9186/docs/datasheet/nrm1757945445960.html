Configurable current settings overview

The current settings for II1ON / II2ON / II3ON are configurable with the nominal values shown in below table.

The device has two configurable current control ranges for I1ON, I2ON, I3ON, I1OFF, I2OFF:

  • Setting 1 (range 1): 0.5 mA - 100 mA
  • Setting 2 (range 2): mA - 150 mA

IHOLD is the hold current used to keep the gate of the external MOSFETs in the desired state.

  • An output stage Gxx is kept ON with the current IHOLD
  • An output stage Gxx is kept OFF with the current - IHOLD
