VCPH charge pump monitoring

To assure enough supply voltage to drive the output stages, the bridge driver provides a VCPH pin undervoltage monitoring function. The differential voltage between pin VCPH and VSCP is monitored for undervoltage. An undervoltage event at pin VCPH is detected in case VVCPH - VVSCP < VVCPH_UV for  t > tVCPH_UV.

The charge pump undervoltage detection threshold is configurable:

Table 1. VCPH undervoltage monitoring configuration
ParameterSymbolNominal valueUnitDefaultToleranceNote
VCPH undervoltage thresholdVVCPH_UV

7.5

8.5

V8.5 VVVCPH_UV_ACC 

Failure reaction of VCPH pin undervoltage detection is fixed to latched error 1 (LE1).
