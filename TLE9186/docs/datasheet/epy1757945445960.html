SDO frame format (next frame response)

The SDO transmits 8 bit global status register + 16 bit read data followed by 8 bit CRC8 (including received SPI register address).

During CSN is set to "low", before a rising edge is sent via SCK, the SDO transmits the global error flag (see Global error flag (GEF))
