CRC8 calculation

As shown in Figure 3 the SDI frame and SDO frame of an SPI command include a CRC field at the end of the frame. For a valid SPI command, the CRC field has to match to the sent content of the SDI and SDO frame. The CRC field has to be filled with the correct calculated CRC8. This chapter includes additional information for the CRC8 calculation for SDI and SDO frame. The CRC calculation uses the CRC8 of SAE J1850 standard polynomial calculation.

Table 1. CRC8 calculation
CRC result width 8 bits
Polynomial 0x1DH
Initial value 0xFFH
XOR value 0xFFH
Check 0x4BH
Magic check 0xC4H
