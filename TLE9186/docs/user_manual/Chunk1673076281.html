Preface

About this document

Scope and purpose

This is the user manual of the product TLE9186QVW. The user manual provides additional information to the datasheet of the 3-phase gate driver TLE9186QVW for BLDC motor application from Infineon Technologies AG.

The user manual describes detailed technical aspects of the device required for integration in a system. The devices to which this manual applies are listed in the table "related devices" below. For the device's specification, please see the respective datasheet.

It contains detailed instructions on how to configure the device and how to use it in the application. This document contains information about:

  • Additional information for each IC module: Additional functional information
  • Diagnostic feature description: Diagnostics (additional information)
  • SPI register definition: SPI (additional information)
  • External components: Application information (additional information)

The following information is given as a hint for the implementation of the device only and shall not be regarded as a description or warranty of a certain functionality, condition, or quality of the device.

Intended audience

This document is intended for engineers who develop applications using TLE9186QVW.

For the device's specification, see the corresponding datasheet.
