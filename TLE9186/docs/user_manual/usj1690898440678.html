Phase feedback monitoring

The device offers a phase feedback monitoring feature to monitor the phases' switching and comparing it to the requested PWM input signals. The following table shows the possibilities for configuration and its related control bits. Some PFB monitoring functions use unfiltered VSHH and VSHL comparator thresholds and other use tPFB_filter filtered VSHH and VSHL comparator signals. Refer to the table below for more information.

Table 1. Configuration options
Configuration option Related SPI control bit or status bit Comment
PFBx function at CSO pin CSO_MUX This configuration is used as well for PFBx output at CSO pin. In case PFBx is mapped on CSO, then it uses filtered VSHH and VSHL thresholds. Filtered with tPFB_filter
Enable/disable PFB monitoring PFB_EN In case phase feedback monitoring is disabled, PFB_LE bit will not be cleared if already set to "1", until an SPI clear by write command
Enable half-bridges HBx_EN PFBx status bits is PFB monitoring function is only enabled in case HBx_EN control bit is set to "1"
PFB monitoring blanking time extension TPFB Configurable time applicable during turn ON of MOSFET
PFB monitoring failure reaction PFB_FM Configurable failure reaction in case PFBx_LE is set to "1"
Fast comparator threshold configuration FAST_CMP_TH Fast comparator threshold VSHH and VSHL used for current controlled output stage feature and PFB monitoring
PFBx status bits PFB3, PFB2, PFB1 PFBx status bits are updated to "1" when filtered VSHH fast comparator threshold is reached and updated to 0 when filtered fast comparator threshold VSHL is reached. Filtered with tPFB_filter
PFB failure detection PFB1_LE, PFB2_LE, PFB3_LE Set to "1" in case one PFBx monitoring detects failure. PFB failure detection uses tPFB_filter filtered signals. Filtered with tPFB_filter
PFBx "high" time counter PFBx_H_CNT Three separate "high" time counters for each SHx phase. This counter starts when filtered VSHH comparator threshold is reached and stops when filtered VSHL comparator threshold is reached. Once it is stopped the value is stored/accessible by SPI read command. Filtered with tPFB_filter
PFBx counter ready bit CNTx_RDY Three separate bits indicate if PFBx_H_CNT is counting (PFBx = 1) or if phase "high" time has finished and PFBx_H_CNT is valid

Phase feedback monitoring is enabled by default and can be deactivated by PFB_EN bit set to "0". In case the half-bridge is disabled by HBx_EN = "0", then PFBx status bits are not updated and PFB monitoring is disabled for the corresponding half-bridge. Only for enabled half-bridges (HBx_EN = "1") the PFBx status bits are updated and PFB monitoring is enabled. In case PFB monitoring is enabled by the HBx_EN control bit, then PFB error reporting is disabled in case VDH undervoltage is detected by the device. PFB error reporting is automatically re-enabled in case VDH undervoltage event disappears. PFBx status bits and PFBx counters will continue to be updated in case VDH undervoltage.

In case an PWM turn ON signal (for example IL1 = "high") the output stage is turned on in normal operation mode. A configurable timer TPFB is started after the drain-source monitoring blanking time tVDS_BLK has elapsed. After TPFB has expired, the phase comparator signals are checked if the phase has been driven towards VSHL or VSHH accordingly. If the comparator feedback does not match to expected turn-on output stage, then a phase feedback monitoring error is detected and the PFB_LE status bit is set to "1". The failure reaction is configurable via control bits PFB_FM. The thresholds VSHH and VSHL of the fast comparators are configurable by control bit FAST_CMP_TH.

If phase feedback monitoring was disabled, then all related status bits are set to "0". If the status bit is set to "1", it will not be automatically reset by deactivation of the feature until an SPI clear by write command. The figure below illustrates configuration possibilities.

In normal mode, if the low-side output stage of a half-bridge is turned ON, the device expects after TPFB to receive a PFB feedback signal showing PFBx = "0".

If the high-side output stage of a half-bridge is turned ON, the device expects after TPFB to receive PFB feedback signal showing PFBx = "1".

The figures below show two examples of correct switching of output stages for high-side and low-side output stages. In case of failure (for example, the output stage does not turn ON, the phase has a short circuit to supply or GND) and the PFBx state is not as expected, the PFB_LE bit is set and the configured failure reaction is triggered.
