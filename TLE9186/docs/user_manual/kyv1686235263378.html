Power supply (additional information)

This chapter provides additional information about the device charge pump power supply, which is described in the datasheet.

The charge pump requires external components and is the supply for floating high-side and low-side drivers in the gate driver unit. The charge pump external required components depend on the use case which is selected. The efficiency of the charge pump directly depends on the selected external components, especially on the forward voltage drop of the selected diode. The lower the forward voltage drop, the more efficient the charge pump works and as well the charge pump operation at low VSCP supply conditions is improved. For both use cases a series resistor and buffer capacitor is needed at the VSCP pin.

In case the charge pump external components are populated for a two stage charge pump, the CP_CFG needs to be set to "0".

In case the charge pump external components are populated for a three stage charge pump, the CP_CFG needs to be set to "1".

Table 1. Charge pump external components for use case
Use case External components Charge pump configuration (CP_CFG) Comments
Typical use case: Two-stage charge pump configuration Three external diodes and three external capacitors. Diode type BAV99, BAS16. CP_CFG = 0B Used for functional range VSCP > 8 V. Charge pump current capability IVCPH < 9 mA (6 x 60 nC @ 20 kHz)
Low VSCP supply use case: Three-stage charge pump configuration Four external diode and four external capacitors. Diode type BAT54. CP_CFG = 1B Used for extended functional range VSCP > 4.5 V. Charge pump current capability IVCPH < 4.8 mA (6 x 40 nC @ 20 kHz). Recommended to set charge pump undervoltage to lower threshold (CP_UV_TH = "1")
In case the driver has to work in low VSCP supply voltages down to 4.5V, an additional diode and switching capacitor has to be added. In this option, the output current capability of the charge pump is reduced by approx. factor of two.
Once the charge pump is enabled by SPI command (CP_EN = "1"), the charge pump requires tON_VCPH to ramp up, see figure below.

The maximum total gate charge for this device is limited by the charge pump current capability. In the datasheet, parameter P_GEN_12_10 specifies the current consumption of the IC when operating it with the total gate charge of a MOSFET in a typical application use case.

The current for parameter P_GEN_12_10 of the datasheet is calculated by IVCPH = number of switching MOSFETs × fPWM × Qg = 6 × 20 kHz × 60 nC = 7.2 mA + additional external circuity supplied by charge pump (1 mA).
