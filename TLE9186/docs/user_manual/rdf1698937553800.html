Gate current sequencer: turn ON and turn OFF of active MOSFET

This chapter provides additional information about current settings and timings for active turn ON and turn OFF of an GHx output stage.

Depending on the configuration of bit GDRV_CFG in register CONFIG_SECURED two different gate current sequencer schemes can be selected:
  • GDRV_CFG = 0B: time programmable referenced gate current sequencer (see Time programmable referenced gate current sequencer)
  • GDRV_CFG = 1B: fast comparator referenced gate current sequencer (see Fast comparator referenced gate current sequencer)
Table 1. Settings
Bit field SPI register Related electrical parameter Comment
GDRV_CFG CONFIG_SECURED N/A Configuration for gate sequencer scheme
GDRV_RNG CONFIG_SECURED N/A Selection of gate current range for all gate currents
FW_CFG CONFIG_SECURED N/A Selection of free-wheeling turn ON/OFF behavior see Freewheeling MOSFET
OFF_CFG CONFIG_SECURED N/A Configuration of switch OFF behavior in case of detected faults leading to gate driver OFF (LE1, LE2) see Failure reaction: latched error (LE1 and LE2)
ION_HS_BNK, ION_LS_BNK ION_HS1, ION_LS1 N/A Turn ON bank configuration for HS and LS output stages
IOFF_HS_BNK, IOFF_LS_BNK IOFF_HS1, IOFF_LS1 N/A Turn OFF bank configuration for HS and LS output stages
I1ON_xx I1ON_HS1, I1ON_LS1, I1ON_HS2, I1ON_LS2, I1ON_HS3, I1ON_LS3 I1ON Pre-charge current I1ON applied during pre-charge phase
I2ON_xx I2ON_HS1, I2ON_LS1, I2ON_HS2, I2ON_LS2, I2ON_HS3, I2ON_LS3 I2ON Charge current I2ON applied during dV/dt phase
ION ON_IOFF_DIDT IxON Charge current ION applied during di/dt phase
I3ON_HS I3ON I3ON Charge current applied during post-charge phase for HSx
I3ON_LS I3ON I3ON Charge current applied during post-charge phase for LSx
I1OFF_xx I1OFF_HS1, I1OFF_LS1, I1OFF_HS2, I1OFF_LS2, I1OFF_HS3, I1OFF_LS3 I1OFF Pre-discharge current I1OFF applied during pre-discharge phase
I2OFF_xx I2OFF_HS1, I2OFF_LS1, I2OFF_HS2, I2OFF_LS2, I2OFF_HS3, I2OFF_LS3 I2OFF Discharge current I2OFF applied during dV/dt phase
IOFF ION_IOFF_DIDT IxOFF Discharge current ION applied during di/dt phase
IDCHG_ST GDRV_CFG3 IDCHG_ST Discharge current for safe state entry
IFW GDRV_CFG3 IFW Freewheeling current
IHOLD GDRV_CFG3 IHOLD Holding current. IHOLD accuracy follows the same specification as other gate current configurations. Please refer to parameter P_GDRV_02_15, P_GDRV_02_16, P_GDRV_02_17
ION_TR GDRV_CFG3 N/A Current step width configuration for ramping phase (applied only for fast comparator referenced gate sequencer)

The time the current is applied for each phase of the gate sequencer scheme is configurable. For the time programmable sequencer scheme, ten timings are required to be configured. For the fast comparator reference sequencer scheme, four timings are required to be configured in bold:

Table 2. Settings
Bit field SPI register Comment
T1ON_HS TON_HS Configurable pre-charge time for HSx
T2ON_HS TON_HS Configurable charge time for HSx (only applicable in case time programmable reference gate current sequencer scheme enabled)
T1ON_LS TON_LS Configurable pre-charge time for LSx
T2ON_LS TON_LS Configurable charge time for LSx (only applicable in case time programmable reference gate current sequencer scheme enabled)
T1OFF_HS TOFF_HS Configurable pre-discharge time for HSx
T2OFF_HS TOFF_HS Configurable discharge time for HSx (only applicable in case time programmable reference gate current sequencer scheme enabled)
T1OFF_LS TOFF_LS Configurable pre-discharge time for LSx
T2OFF_LS TOFF_LS Configurable discharge time for LSx (only applicable in case time programmable reference gate current sequencer scheme enabled)
T3OFF_HS T3OFF Configurable post-discharge time for HSx (only applicable in case time programmable reference gate current sequencer scheme enabled)
T3OFF_LS T3OFF Configurable post-discharge time for HSx (only applicable in case time programmable reference gate current sequencer scheme enabled)

Cross current protection time is configurable for active and freewheeling MOSFET separately by bit fields TCCP and TCCP_FW in register GDRV_CFG1. Additionally the applied clock ratio of the cross current protection time is configurable by bit TCCP_CFG in order to reduce the TCCP by a factor of two. By offering this option the user can select the cross current protection time in the range from either nominal 240 ns up to 3840 ns OR nominal 120 ns up to 1920 ns.
