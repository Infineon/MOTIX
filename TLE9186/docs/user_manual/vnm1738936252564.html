Guidance for unacceptable error detection

Any error reported by the device, preventing the device to go to normal operation mode OR causing safe state entry and preventing to toggle the Gxx output pins is considered as unacceptable error/failure detection. Assessment if an error detection is an unacceptable error depends on:
  • Application use case
  • Enabled and used functions of the device (for example: current sense amplifier, window watchdog)
  • Device failure configuration
Therefore, the assessment of which error detection is an unacceptable error detection is the users responsibility. The list below provides guidance and recommendations on which errors are considered as an unacceptable error:
  • Internal regulator overvoltage detection (REG_OV status bit) – not recommended to enter normal operation mode
  • OTP error detection (OTP_ERR status bit) – not recommended to not enter normal operation mode
  • VSCP undervoltage shutdown detection (VSCP_UV_SD status bit)
  • VSCP overvoltage shutdown detection (VSCP_OV_SD status bit)
  • Charge pump undervoltage detection (VCPH_UV status bit) in case charge pump enabled by SPI command (CP_EN = "1")
  • In case CSA function used in application: current sense amplifier internal supply undervoltage detection (CSA_SUP_UV status bit)
  • In case ERR_N pin used in application: ERR_N pin short to supply detection (ERRN_SHORT status bit), ERR_N pin cannot be used as error indication path towards microcontroller
  • Thermal shutdown events (TSD_IC status bit, TSD_CP status bit)
  • Latent fault detection (LAT_FAULT status bit set to "1"): latent fault detection in safety barrier - not recommended to enter normal operation mode
  • In case VDH connected to motor bridge supply: VDH undervoltage detection (VDH_UV status bit set) – drain-source overvoltage on high-side MOSFET cannot be detected reliably
  • VIO supply error detection (VIO_UV status bit AND VIO_OV status bit)
  • SOFF_GDRV bit set to "0" in power-up mode: indication that at least one Gxx output stage is not correctly turned OFF – not recommended to enter normal operation mode

In case unacceptable error detection cannot be cleared by SPI clear by write command it is highly recommended to force safe state entry or to go to sleep mode.
