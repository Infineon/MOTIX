State machine (additional information)

This chapter provides additional information about the device state machine, which is described in the datasheet.

The device has three modes of operation:

  • Sleep mode: low quiescent mode of device (INH_N = "low")
  • Power-up mode: configuration of the device possible (INH_N = "high")
  • Normal operation mode: active mode, where Gxx output stages can be turned on and off (INH_N = "high")

Transition between power-up mode and normal operation mode can be controlled by the microcontroller by SPI register PWR_MOD_CFG (register bits MODE_CTRL_x).

The following simplified table shows the behavior of the device depending on status of INH_N and control bits HBx_EN bit settings.

Table 1. State table
INH_N Mode Control bit for half-bridge ERR_N Output stages GHx and GLx
"low" Sleep mode X OFF OFF, safe state (passive discharge)
"high" Power-up mode X "low" OFF, safe state (passive discharge)
"high" Normal-operation mode disable "high" see uwk1686235093390.html#uwk1686235093390__note_ivv_cct_sxb OFF, safe state (passive discharge)
"high" Normal-operation mode enable "high" see uwk1686235093390.html#uwk1686235093390__note_ivv_cct_sxb ON, controlled by PWM inputs (if charge pump enabled and no LE1)
Note:
The ERR_N pin is an open drain output pin. The resulting ERR_N level at the microcontroller input will be pulled up to "high" level due to the external pull-up resistor RERR_PU. ERR_N pin follows error indication according to configured failure behavior.
