Electrical characteristics table - external component deviation

The specification of the external component values are specified including the deviation of the nominal values. Deviations included in minimum and maximum values listed in external components deviation specification. Product-, temperature- and aging deviation included. Include voltage derating. Unless otherwise specified, the deviation for external components are:

  • Resistor: ±10%
  • Capacitor: -50% ... +30%
