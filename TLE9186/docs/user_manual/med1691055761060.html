PFB "high" counter feature

The device includes a counter to measure the PFBx "high" time. The feature is enable for each phase in case the half-bridge is enabled (HBx_EN = 1).

If VSHx > VSHH, the counter starts to count until VSHx < VSHL. The value for each phase is stored in associated register PHASEx_CNT in bit field PFBx_H_CNT. If VSHx > VSHH for longer than the maximum counter time, then 0x0FFFH is written to PFBx_H_CNT. The clock frequency of the counter is fPFB_CNT (P_DIAG_08_02).

The updated counter value can be read by the microcontroller once CNTx_RDY status bit is set to "1". When the internal CNTx counter is restarted, then the CNTx_RDY bit is cleared but the PFBx_CNT is kept until an updated counter value is available.

Each time a measured PFBx "high" time is written by the device into bit field PFBx_H_CNT, the PFBx_CNT_UPD bit is set to "1" to signalize an updated value. Bit PFBx_CNT_UPD can be cleared by SPI clear by write command by the microcontroller. This mechanism is used to check if PFBx_H_CNT has been updated since last SPI clear command.
Note:
In case CNTx_RDY status bits are not used for read-out by the microcontroller it is recommended to read the PFBx_H_CNT counter register during low-side output stage ON phase.
The PFBx "high" counters can be used by the microcontroller to check if the phase switching follows the applied duty cycle at the PWM input pins. The microcontroller accesses the three PFBx "high" counters and counter ready bits in registers PHASE1_CNT, PHASE2_CNT, PHASE3_CNT by three SPI read-out commands. The microcontroller receives a "high" counter value for each phase, which can be used to check and confirm if the phases are following the PWM signal and duty cycle. Since the SPI communication and read-out commands may happen asynchronously to the motor control scheme, the received PFBx "high" counters represent a snapshot of an applied switching period. The CNTx_RDY bit indicates if the "high" counter of the associated phase is still counting or if the phase is "low" and the counter value is the most recent. The following figure shows an example.

The device includes three separate PFBx counter update bits (PFBx_CNT_UPD) for each PFBx status register PFB1_H_CNT, PFB2_H_CNT and PFB3_H_CNT. The PFBx_CNT_UPD bit set to “1” by device when a counter measurement has finished and PFBx_H_CNT value is written to respective PFBx status register. PFBx_CNT_UPD bit is set to "1" by the device in case an updated value of the PFBx_H_CNT is written by the device in the respective PFBx status register. The microcontroller has to reset the PFBx_CNT_UPD update bit to "0" by SPI write command.

This mechanism can be used by the microcontroller to verify the PFBx counters are not stuck but continuously updated by check of PFBx_CNT_UPD bit during SPI read command of PFBx status registers.
