      • Window watchdog

        An integrated window watchdog supervises the integrity of the communication with the microcontroller. The watchdog is used to monitor the software execution of the microcontroller and to detect and report errors or loss of SPI communication via SPI status registers or ERRN. Failure behavior is configurable by control bits WD_FM.

      • PWM monitoring
      • Digital output pin failure detection

        Both digital output pins ERR_N and SDO include an output pin failure detection. Failure detection can be read-out via SPI. In case of failure detection the affected pin is deactivated.
