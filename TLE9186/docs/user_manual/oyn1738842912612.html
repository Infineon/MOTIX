Freewheeling MOSFET

As described in previous chapters, the device offers two different gate current sequencer schemes for the active MOSFET. For the passive freewheeling MOSFET, the device offers some configuration possibility as well, which changes the gate currents applied during turn ON and turn OFF of the freewheeling MOSFET. The behavior can be selected by control bit FW_CFG in SPI register CONFIG_SECURED:

  • FW_CFG = "0" (default): freewheeling device does not use precharge/predischarge phase
  • FW_CFG = "1": freewheeling device uses precharge/predischarge phase (t1ON_HS, t1ON_LS, t1OFF_HS,t1OFF_LS)
