SPI status bits relation to global status byte

The SDO shifts out the global status register during the first eight SCK cycles to provide an overview of the device status shown in Table 1 as following (in Figure 1). The global status register consists of the following global status flags:

  • B7 (OFC flag): at least one SPI frame is corrupted
  • B6 (LFOK flag): last received SDI frame is correct
  • B5 (VSUPE flag): supply status flag
  • B4 (MISC flag): miscellaneous status flag
  • B3 (BDRE flag): bridge driver status flag
  • B2 (DE flag): device error indication using SPI register failure detection bits configured as error, latched error 1, latched error 2 OR in case safe state is forced
  • B1 (DW flag): device warning indication using SPI register failure detection bits configured as warning
  • B0 (POR): power on reset indication
Note:
In case the SPI timing parameters according to datasheet are violated (for example CSN leading edge < tCSN_LDEL), then the global status byte content might be set to 0x00. It is recommended to ignore the received SDO frame and to resend the SPI command request.

DE status flag is used in the application to:

  • Indicate a failure has detected
  • Feedback towards microcontroller in case safe state is entered/forced

DE status flag and ERR_N pin behavior are linked for failure reaction which are configured as error, latched error 1, latched error 2:

  • In case ERR_N pin "low", then DE status bit set to "1"
  • In case ERR_N pin is not driven actively "low" by the device, then DE status bit "0"

In power-up mode, safe state is internally forced and ERR_N pin is set to "low". The DE status flag is set to "1" independent of any failure detected by the device.
