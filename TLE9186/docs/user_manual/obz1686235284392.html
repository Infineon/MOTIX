Gate driver (additional information)

This chapter provides additional information about the device gate driver output stages, which are described in the datasheet.

The device integrates six floating gate drivers capable of controlling a wide range of N-channel MOSFETs. These are configured as three high-side and three low-side drivers, forming a 3-phase inverter for controlling a BLDC motor. The output stages Gxx are deactivated by default in power-up mode and can be activated in normal operation mode.

The device offers the possibility to map PWM together. Either the GHx and GLx output stages of each phase are controlled separately by corresponding IHx_N and ILx input pins OR IHx_N input pins are deactivated and ILx input pins are used for corresponding half-bridge HBx control (one PWM input per half-bridge). With this feature the PWM input pins needed from microcontroller can be reduced by half. The control bit to enable this feature is SPI bit PWM_MAP in SPI register CONFIG_SECURED. In case PWM_MAP bit is set to "1":
  • The ILx is propagated to both HSx and LSx of the corresponding half-bridge
  • AND IPV_CCP failure reaction is deactivated (status bit not set, failure reaction not triggered)
  • AND PWM alternation check is deactivated (PWM_CHCK)

A MOSFET turn-on request is defined as:

  • HS turn-on request:
    • in case PWM_MAP = "0": when synchronized IHx_N high-low transition detected
    • in case PMW_MAP ="1": when synchronized ILx high-low transition detected
  • LS turn-on request:
    • when synchronized ILx low-high transition detected

In normal operation mode, depending on bits HBx_EN, CP_EN, each high-side and low-side MOSFET can be:

  • Kept off with the passive discharge (CP_EN = "0")
  • Kept off actively (CP_EN = "1", HBx_EN = "1")
  • Activated, and following PWM input pattern, applied by the microcontroller at the IHx_N and ILx pins (CP_EN = "1", HBx_EN = "1")

In normal operation mode the output stages can be activated. By default, the output stages are deactivated in normal operation mode. To activate the output stages, bits HBx_EN have to be set to "1" in register GEN_CFG1. Each HBx_EN bit enables/disables one half-bridge (refer to the table below).
